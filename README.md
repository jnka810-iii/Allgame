## 👾 Space Invaders — Pixel Edition

เกมยิงยานอวกาศแนว Space Invaders สไตล์พิกเซลอาร์ต เขียนเสร็จในไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไรเพิ่ม

### วิธีเล่น

ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome, Edge, Firefox) แล้วกด **Start Game** หรือกด `Enter`

### ปุ่มควบคุม

| ปุ่ม | การทำงาน |
|------|----------|
| `←` `→` หรือ `A` `D` | เลื่อนยานซ้าย–ขวา |
| `Space` (หรือ `K`) | ยิง |
| `Enter` | เริ่มเกมจากหน้าเมนู (ระดับ Normal) |
| ปุ่ม ◀ ● ▶ บนจอ | ควบคุมบนมือถือ / แท็บเล็ต |

### ฟีเจอร์

- **3 ระดับความยาก:** Easy, Normal, Hard ยิ่งยาก ศัตรูยิ่งยิงถี่และเดินเร็วขึ้น
- **กราฟิกพิกเซลอาร์ต:** ยานและศัตรูวาดจาก bitmap ทีละพิกเซล มีเอฟเฟกต์เส้นสแกนแบบจอ CRT
- **บังเกอร์ทำลายได้:** กำแพงป้องกันจะแหว่งไปทีละส่วนเมื่อโดนกระสุน
- **ไอเทมพลังพิเศษ:** ศัตรูมีโอกาสทิ้งไอเทมเมื่อถูกทำลาย
  - `RAPID FIRE` ยิงเร็วขึ้น 8 วินาที
  - `SPREAD SHOT` ยิงกระจาย 3 ทาง 8 วินาที
  - `SHIELD` เกราะกันกระสุนได้ 3 ครั้ง
  - `EXTRA LIFE` เพิ่มชีวิต 1 ดวง
- **บอส:** ทุก ๆ 5 ด่านจะมีบอสโผล่มา เมื่อเลือดเหลือน้อยจะโกรธและยิงถี่ขึ้น ล้มบอสได้โบนัสคะแนนก้อนใหญ่
- **เสียงประกอบ:** สร้างเสียงสดด้วย Web Audio API ไม่ใช้ไฟล์เสียง ปิด/เปิดได้ที่ปุ่ม `SOUND`
- **ตารางคะแนนสูงสุด:** เก็บ 10 อันดับแรกไว้ในเครื่อง (localStorage) พร้อมใส่ชื่อผู้เล่น

### กติกาและคะแนน

| เหตุการณ์ | คะแนน |
|-----------|-------|
| ศัตรูแถวบนสุด (ต้องยิง 2 ครั้ง) | 150 (+20 เมื่อยิงโดนครั้งแรก) |
| ศัตรูแถวกลาง | 80 |
| ศัตรูแถวล่าง | 50 |
| ล้มบอส | 1,000 + (ด่าน × 100) |

- เริ่มเกมด้วย 3 ชีวิต และได้ชีวิตเพิ่มทุก ๆ 3 ด่าน (สูงสุด 9)
- ถ้าศัตรูเดินลงมาถึงแนวยานของเรา **เกมจบทันที**
- ผ่านครบ 10 ด่านจะชนะเกม

> หมายเหตุ: ฟอนต์ `Press Start 2P` โหลดจาก Google Fonts ถ้าไม่มีอินเทอร์เน็ตเกมยังเล่นได้ แต่จะแสดงเป็นฟอนต์สำรองแทน

## ⛵ hello.py — ASCII Art เรือใบ

โปรแกรม Python ที่พิมพ์ `Hello, World!` วาดเรือใบด้วยตัวอักษร ล้อมด้วยกรอบ `*` และแสดงข้อความต้อนรับไว้กึ่งกลาง

### วิธีรัน

ต้องมี Python 3.x (ไม่ต้องติดตั้งไลบรารีเพิ่ม)

```bash
python hello.py
```

> บน Windows ถ้าคำสั่ง `python` ใช้ไม่ได้ ให้ลอง `py hello.py`

### ตัวอย่างผลลัพธ์

```
Hello, World!
**************************************************
                               |
                              /|\
                             / | \
                            /  |  \
                           /   |   \
                          /    |    \
                         /     |     \
                        /______|______\
                       /      /|     /
                      /______/ |____/
                             | |
                     ________|_|____________
                  .-'         /            /|
               .-'___________/____________/ |
              /___________________________| /
              \                           \/
               `-._____________________.-'
~~~~~~~~~~~~~~~~~~~~\_______________/~~~~~~~~~~~~~~~~
       ~~~~~~~        ~~~~~~~~        ~~~~~~~

          Welcome to the Ship ASCII Art!
**************************************************
```

### โค้ดทำงานอย่างไร

1. เก็บภาพเรือใบไว้ในสตริงหลายบรรทัด (`"""..."""`)
2. สร้างกรอบด้วย `"*" * 50` ซึ่งได้เครื่องหมาย `*` 50 ตัว
3. จัดข้อความให้อยู่กึ่งกลางด้วย `.center(50)`
4. พิมพ์กรอบบน ภาพเรือ ข้อความ และกรอบล่างตามลำดับ

### ลองปรับแต่ง

- เปลี่ยนตัวอักษรของกรอบ เช่น `"=" * 50` หรือ `"#" * 50`
- เปลี่ยนข้อความในตัวแปร `messege` เป็นข้อความของคุณเอง
- วาดภาพ ASCII Art ใหม่ลงในตัวแปร `text`
