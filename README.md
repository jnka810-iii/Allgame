# Allgame

โปรเจกต์ Python เล็ก ๆ สำหรับฝึกเขียนโค้ดและทดลองทำ ASCII Art

## ฟีเจอร์

- พิมพ์ข้อความ `Hello, World!`
- แสดงภาพเรือใบแบบ ASCII Art
- มีกรอบ `*` ล้อมรอบภาพ และมีข้อความต้อนรับจัดกึ่งกลาง

## สิ่งที่ต้องมี

- Python 3.x

## วิธีรัน

```bash
git clone <URL ของ repo นี้>
cd Allgame
python hello.py
```
